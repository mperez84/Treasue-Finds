Connect as the owner

Use your private GitHub access key to publish changes to your shop.

Your key goes directly to GitHub. This dashboard keeps it in memory for this tab only. Closing or reloading the page disconnects it. Never send your key in a chat.

First time? Set up my access key
  1. Open GitHub’s access-key page ↗ and sign in to mperez84.
  2. Name the key Treasure Finds Dashboard and choose an expiration date.
  3. Under Repository access, choose Only select repositories and select Treasue-Finds.
  4. Under Repository permissions, set Contents to Read and write. Leave other permissions unchanged.
  5. Generate the key, copy it and paste it into the field above. Keep it in your password manager so you can connect again.

This key can change your website files. Only use it on your own device and this dashboard. If it expires, create a replacement the same way.
